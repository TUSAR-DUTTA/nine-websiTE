# $NINE × $GME — 9 LIVES. ONE MORE COMEBACK.

> *"Every cat has nine lives. But some cats just refuse to stay dead. That's $NINE."*

An underground crypto terminal, digital identity network, and community comeback headquarters built for $NINE.

---

## ⚡ Core Philosophy & Architecture

- **$NINE × $GME Spirit**: GME represents the comeback; NINE represents nine lives. Crashes are not hidden from the narrative — crashes become chapters. Comebacks become chapters.
- **No Childish Gamification**: Absolutely no XP, no character levels, and no mobile game badges. Instead, status is derived from real on-chain holding history, public Twitter activity, community recognition, wallet flexing, and visible achievements.
- **Aesthetic**: Underground Bloomberg Terminal meets internet meme culture. Charcoal/black base (`#08080a`), phosphor greens (`#00ff66`), warning reds (`#ff3344`), imperial golds (`#ffd700`), CRT scanlines, grain overlays, and asymmetrical command panels.

---

## 🛠 Features Implemented

1. **Top Live Marquee & Market Ticker**:
   - Streaming ticker with price, 24h change (+34.8%), Mcap ($9.14M), Liquidity ($1.42M), Holders (9,421), and volume.
   - Live events stream with buys, sells, X posts, fumbles, and comeback alerts.

2. **Hero Section ("NINE Is Still Alive")**:
   - High-impact typography, cybernetic nine-lives cat mascot with breathing scanlines.
   - Interactive SVG/Canvas Comeback Chart annotated with historical drawdowns and rallies (Life 01: -88% → +420%, Life 02: -74% → +650%, Life 03: -69% → +310%, Life 04: Active breakout).
   - Quick action triggers: `[BUY $NINE]`, `[JOIN THE TERMINAL]`, `[VIEW FUMBLE BOARD]`.

3. **The Nine Lives Tracker**:
   - Nine distinct cat-life slots: Life 01 (Survived), Life 02 (Survived), Life 03 (Survived), Life 04 (Active), and Lives 05–09 (Locked).
   - Interactive chapter drawer with drawdown telemetry, memes, and on-chain proofs.

4. **Live NINE Terminal (Command Center)**:
   - Live streaming activity feed combining on-chain swaps, CT tweets, whale accumulation, and comeback signals.
   - Filter by `ALL`, `BUY`, `POST`, `FUMBLE`, `COMEBACK`.
   - Streaming controls: Pause/Resume toggle and speed simulation.

5. **The Fumble Board (Signature Feature)**:
   - Tracks funny, memorable wallet exits and panic sells before massive rallies.
   - Non-toxic community reactions: `LOL` (😂), `PAIN` (💀), `RESPECT` (🫡), `HE IS COOKED` (🍳), `HE'LL BE BACK` (🐈).
   - Integrated Fumble Detection Engine explainer.

6. **The Bag Board**:
   - Dynamic on-chain recognition for notable community members:
     - `BIGGEST BAG`
     - `LONGEST HOLDER`
     - `EARLY CAT`
     - `COMEBACK HOLDER`
     - `CONVICTION HOLDER`
     - `MOST ACTIVE HOLDER`
     - `RE-ENTRY ARTIST`
     - `MOST CHAOTIC TRADER`

7. **Bag Workers (X / Twitter Social Leaderboard)**:
   - Ranks public members based on creative contribution, daily consistency, impressions, and original memes.
   - Decoupled from vanity follower counts using the transparent 4-factor scoring formula.

8. **Slick Command-Center Profile Slide-over**:
   - Clicking ANY user or wallet anywhere across the site opens an interactive side-drawer command dossier displaying:
     - Avatar, display name, verified badges, custom titles.
     - Abbreviated wallet address with copy function.
     - Holdings in $NINE and USD value, holding duration ("Since 58 days ago"), buy/sell history summary.
     - X statistics, social activity density gauge, and community status labels.
     - Equipped Arcade Skin styling effects.
     - Interactive tip tool to send $NINE to community members.

9. **Nine Wall (Community Graffiti & Memes)**:
   - Live message board with filters for `HOT`, `NEW`, `COMEBACKS`, `FUMBLES`, `ART`, and `BAG WORK`.
   - Client and server-side anti-spam verification, character limits, rate limiting.
   - Multi-emoji status reaction bar.

10. **"Where Did The Cat Go?" (Wallet Trail Visualizer)**:
    - Step-by-step animated tracking of large on-chain token migrations from cold storage through multi-sig buffers into DEX liquidity pools.

11. **NINE Pulse & The Comeback Signal**:
    - Live ecosystem activity gauges: Community (94%), Social (89%), Trading (82%), Memes (97%).
    - "THE CAT IS MOVING" Comeback Radar indicator with transparent calculation formulas.

12. **The Nine Arcade (Digital Identity Marketplace)**:
    - Burn or spend $NINE to acquire terminal skins (`GME TERMINAL`, `CRT BURNT`, `RED ALERT`, `AFTER THE CRASH`, `CAT IN THE DARK`, `NINE LIVES GOLD`).
    - Live real-time preview on the user's active dossier with instant equipment and balance deductions.

13. **The Comeback Archive**:
    - Permanent historical timeline instead of a roadmap: `SURVIVAL → CRASH → SILENCE → COMEBACK → NEW CHAPTER`.
    - Detailed chapters documenting the Day 1 dump, the Delisting FUD, and the 900-Post Raid.

14. **Audio Synthesizer**:
    - Subtle retro terminal beeps, clicks, and comeback chimes generated via the Web Audio API without heavy external audio files.

15. **Wallet Connection & Persona Switcher**:
    - Demo persona switcher allowing instant testing as a Whale Titan, Bag Worker, Fumble Survivor, or fresh new wallet.

16. **Hidden Admin Dashboard (`/admin`)**:
    - Moderation tools for wall posts, stream speed controls, simulated Chapter triggers, and emergency alert broadcasts.

## 🚀 Running the Project

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Or build and launch production server
npm run build
npm run start
```

Access the application at `http://localhost:3000`.
Admin controls accessible via `http://localhost:3000/admin` or the shield icon in the header.
